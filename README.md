# Rock ✊ Paper ✋ Scissors ✌️ Game 🎮🔥

A fun and interactive web app built with **HTML, CSS, and JavaScript** where you can challenge the computer in the classic Rock‑Paper‑Scissors game. 🖥️⚡

## ✨ Features
- 🎯 Play Rock, Paper, or Scissors against the computer  
- 🤖 Random computer choice each round  
- 🏆 Score tracking for you vs. computer  
- 🔄 Reset button to start fresh anytime  
- 🎨 Simple design with clean UI
